# Ocean UI — produkční nasazení 2026-09-27

Nasazení mění pouze `public/index.html` a `public/ocean-workspace.css`:
větší text a ovládací prvky, popisy DCA a pozic, čitelnější karty,
scrollování na menších obrazovkách a chybové hlášky bez překrývání ovládání.

Základ je commit `88d8383`. Před uploadem bylo porovnáno 114 souborů
běžící produkce s balíčkem včetně kompilovaného backendu a Python workeru;
lišily se pouze dva výše uvedené soubory. Konfigurace, credentials,
obchodní pravidla a databázové migrace nejsou součástí změny.
Nový panel vysvětlení strategie a změny Kryptotron v1 nejsou nasazené;
jejich testnet acceptance zůstává nedokončený.

## Ověření balíčku

- TypeScript build, 28 Node testovacích souborů, 73 Python testů prošlo.
- 18 kontrol rozložení a dosažitelnosti ovládání na šesti velikostech
  obrazovky (320–1440 px), dialogy DCA/pozic, prázdný a zastaralý stav,
  přihlašovací obrazovka; bez JavaScript chyb. Pouze simulovaná data.
- První testování pod `/tmp` narazilo na to, že test izolace workerů
  záměrně překrývá `/tmp`. Stejný balíček byl přesunut do pracovní složky
  mimo `/tmp` a celý verify průchod následně prošel beze změn kódu.
